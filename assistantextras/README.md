# Assistant Cogs

[Discord Red Cog](https://github.com/Cog-Creators/Red-DiscordBot) to expose tooling from your existing cogs to [Assistant](https://github.com/vertyco/vrt-cogs/tree/main/assistant).

## Installation

```
[p]repo add robloach-cogs https://github.com/robloach/robloach-cogs
[p]cog install robloach-cogs assistantextras
[p]load assistantextras
```

## Usage

```
[p]assistantextras
```
